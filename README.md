*نظام إدارة المدرسة (School Management System)
*نبذة عن المشروع:
هذا المشروع عبارة عن نظام بسيط لإدارة شؤون المدارس، قمنا بتطويره كجزء من مشروعنا البرمجي لتعلم وتطبيق أساسيات تطوير الويب. يهدف النظام إلى تنظيم بيانات المدرسة الأساسية (الطلاب، المعلمين، والمواد الدراسية) في مكان واحد ليسهل التعامل معها والوصول إليها بسرعة.

*مميزات النظام
إدارة سهلة للبيانات: لوحة تحكم بسيطة تتيح إضافة وعرض بيانات الطلاب، المعلمين، والمواد الدراسية.
نظام العلامات: إمكانية إدخال درجات الطلاب لكل مادة، مما يساعد في متابعة أداء الطالب
واجهة مستخدم واضحة: تصميم بسيط باللغة العربية يسهل على المستخدم التعامل معها
قاعدة بيانات منظمة: هيكلية مرتبة للجداول (جداول للطلاب، المواد، والنتائج)
سهولة التصفح: روابط مباشرة للتنقل بين الصفحات (الطلاب، المقررات، النتائج)
